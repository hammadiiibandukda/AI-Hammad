# AI-Hammad

A workspace repository, set up for development with [Claude Code](https://claude.com/claude-code).

## Overview

A place for Cloaked design/marketing prototypes and working files. Prototypes
are plain HTML + CSS, single file, no build step — open them directly in a
browser.

## Getting started

1. Clone the repository.
2. Add your project's code and dependencies.
3. Document conventions and commands in [`CLAUDE.md`](./CLAUDE.md) so future
   sessions (human or AI) have the context they need.

## Repository layout

```
.
├── README.md        Project overview (this file)
├── CLAUDE.md        Context and conventions for Claude Code
├── downloads.html   cloaked.com/downloads page prototype
└── .gitignore       Ignored files and directories
```
