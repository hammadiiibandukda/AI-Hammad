# AI-Hammad

A workspace repository, set up for development with [Claude Code](https://claude.com/claude-code).

## Overview

This repository is currently a fresh scaffold. It's ready to grow into a real
project — add source code, tests, and tooling as the work takes shape.

## Getting started

1. Clone the repository.
2. Add your project's code and dependencies.
3. Document conventions and commands in [`CLAUDE.md`](./CLAUDE.md) so future
   sessions (human or AI) have the context they need.
